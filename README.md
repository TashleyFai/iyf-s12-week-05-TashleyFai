# Week 5: DOM Manipulation

**Repository:** `iyf-s12-week-05-TashleyFai`

This project demonstrates my understanding of JavaScript DOM manipulation through an interactive To-Do List, DOM practice exercises, and five daily challenges.

## Project Overview

The main project is an interactive To-Do List that allows users to manage their tasks.

## Features

- Add new tasks.
- Mark tasks as completed.
- Delete individual tasks.
- Filter tasks by All, Active, and Completed.
- Display the number of remaining tasks.
- Clear all completed tasks.
- Edit tasks by double-clicking.
- Save edits using Enter and cancel using Escape.
- Use event delegation to handle task interactions.

- Select and manipulate HTML elements using JavaScript.
